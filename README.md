# Netflix Data Cleaning using Python & Pandas

## Project Overview

This project focuses on cleaning and preprocessing a Netflix movies dataset using Python and Pandas.

## Tools Used

- Python
- Pandas
- Jupyter Notebook

## Data Cleaning Steps

- Removed unnecessary spaces from column names
- Standardized column names
- Checked missing values
- Handled duplicate records
- Converted data types
- Cleaned date-related columns
- Extracted year from release year/date where required

## Dataset

Netflix movies dataset containing information about movies available on Netflix.
